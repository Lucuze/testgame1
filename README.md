# 똑똑 생활왕 👑

2026년도 교육학개론 중간고사 대체 과제

지적장애 초등 저학년을 위한 생활 기술 학습 게임

## 게임 모드
- 🚦 **안전 히어로**: 안전한 행동 판단하기 (문제 22개)
- 🤒 **몸이 아파요**: 아플 때 올바른 대처 방법 알기 (문제 20개)
- 🍽️ **식사 예절 챔피언**: 바른 식사 예절 배우기 (문제 21개)

## 주요 기능
- 난이도 선택 (하/중/상) — 2~4지선다
- 문제 개수 선택 (5/10/15문제)
- 스톱워치 모드
- 💡 힌트 시스템 (문제당 최대 3회)
- 🔥 연속 정답 콤보 표시
- 🦉 SD 부엉이 마스코트 반응 (기쁨/위로/놀람/춤)
- 🎊 퍼펙트 이스터에그 (힌트 0회 + 100% 달성 시)
- 📊 기록표 & 성장 그래프
- 🏆 리더보드 (localStorage 기반)
- 🖨️ 결과 인쇄 기능
- ⚙️ 배경음/효과음 볼륨 설정

## 대상
지적장애 초등 1~2학년

## 교사 모드
- 비밀번호: **1234**
- 기록표 초기화, 리더보드 조회 가능

## 수행평가 활용
결과 화면의 **"교사에게 보여주기"** 버튼으로 전체화면 결과 확인 가능

## 기술 스택
- 순수 HTML + CSS + JavaScript (외부 라이브러리 없음)
- Web Audio API 효과음
- localStorage 기록 저장
- 갤럭시 태블릿/Android Chrome 최적화
