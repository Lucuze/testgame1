## 📱 APK 다운로드 및 설치

### QR코드로 바로 다운로드
![QR코드](https://api.qrserver.com/v1/create-qr-code/?size=200x200&data=https://github.com/Lucuze/testgame1/releases/latest/download/app-debug.apk)

### 설치 방법 (Android)
1. 위 QR코드를 스캔하거나 [최신 릴리즈](https://github.com/Lucuze/testgame1/releases/latest)에서 `app-debug.apk` 다운로드
2. Android 설정 → 보안 → **알 수 없는 앱 설치** 허용
3. 다운로드한 파일을 탭하여 설치
4. **똑똑 생활왕 👑** 아이콘을 탭하여 실행!

> 💡 선생님께: 학기 초 태블릿 세팅 시 "알 수 없는 앱 설치 허용"을 미리 켜두시면 학생들이 QR코드만으로 바로 설치할 수 있습니다.
